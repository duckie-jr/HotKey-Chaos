# HotKey Chaos

HotKey Chaos is a highly customizable, web-based soundboard application. It allows you to build a personal library of sound tiles, bind specific sounds to keyboard hotkeys, and play sounds instantly with the press of a button. 

You can customize the color of your tiles, adjust the volume and bass boost on a per-tile basis, and trigger sounds using different playback modes (such as Overlap, Interrupt, and Loop).
